# Public research release v1.0.0

## Main result

The Meissner degenerations are the unique minimum-volume members of the width-one regular-tetrahedron confocal Peabody family.

## Exact reduction

\[
\operatorname{Vol}K(\mathbf e,\boldsymbol\sigma)
=
V_M+\Phi(e_1)+\Phi(e_2)+\Phi(e_3),
\]

independent of all eight orientation patterns.

## Analytical compression

The earlier local/bulk/tail positivity certificate has been compressed to three lemmas:

1. \(\Phi(1)>3/10000\);
2. \(\Phi''(e)<-1/25000\) for \(0<e<1\);
3. strict concavity gives \(\Phi(e)>3e/10000>0\).

The compressed certificate uses 324 terminal rectangles, down from 2,590.

## Reproducibility

The repository contains the frozen theorem package, release-audit artifacts, exact manifests and hashes, proof-authority Python scripts, independent R and Mathematica semantic audits, and the current manuscript.

## Scope limitation

This release does not solve the global three-dimensional Blaschke-Lebesgue problem and does not claim a theorem for arbitrary Peabodies or semi-regular tetrahedral bases.
